# Repository instructions

- Read `spec.md` completely before implementation; it is the product and architecture source of truth.
- Follow the eight implementation phases in Section 17 and verify each phase before continuing.
- Keep React/Vite frontend code separate from Express/Mongoose backend code.
- Add tests for business logic and security boundaries as they are implemented.
- Never expose canonical solution fields, provider credentials, or private session data in public API responses or frontend bundles.
- Keep generated cases fictional and validate them before publication.
- Update `README.md` and `.env.example` when setup or configuration changes.
